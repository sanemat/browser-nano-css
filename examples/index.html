Layout: bring your own CSS

browser-nano-css does not do layout. The navigation above is a plain <nav><ul> — browser-nano-css leaves it unstyled. The horizontal flex layout comes from style.css: 

/* Your CSS — not part of browser-nano-css */
nav ul {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
  list-style: none;
  padding: 0;
}
